REPUBLIKA - map prototype (GitHub Pages ready)

Open index.html in a browser (internet only needed for the Google Fonts; falls back to Georgia offline).
To host: push this folder to a GitHub repo and enable Settings > Pages > deploy from branch.

Files
  index.html   page shell
  style.css    map styling (parchment / Victoria 3-inspired political map look)
  app.js       map rendering, labels, trade lanes and port labels, interaction
  trade.js     34 trade nodes and the sea-lane network (generated by tools/route.py), in map units
  neighbors.js outlines of surrounding lands as polities stood in 1892 (Natural Earth via world-atlas, public domain)
  data.js      simplified boundaries (geoBoundaries ADM0-ADM3, CC BY 4.0, Runfola et al. 2020)
  assets/      paper.jpg (screen-space paper grain), land.jpg (watercolour land texture)

Map style notes
  - Trade nodes and lanes: edit trade.js. 'nodes' are ports (hub:1 = gold marker), 'lanes' are island-to-island routes,
    'out' are overseas trades that run to the edge of the chart (frame). Lanes are drawn as broken lines; style in style.css (#lanes).
  - 'frame' in trade.js is the outer boundary of the chart: the view cannot leave it and the overseas lanes end past it.
  - Region colours: WASH array in app.js.
  - Label sizing/limits: addLab() and LIM in app.js.
  - Pan/zoom limits: clampVB() in app.js (uses the frame from trade.js).
  - Neighbour labels: FOR array in app.js; colours are in neighbors.js.

Trade network (v2)
  - Nodes: 4 hubs (Manila, Iloilo, Cebu, Zamboanga), 2 other ports open to foreign trade (Sual, Legazpi), 25 coasting ports (incl. Dapitan, Rizal's place of exile),
    and 3 overseas ports (Hong Kong, Singapur, Sandakan). Lesser ports appear as you zoom in.
  - Lanes: k1 = steamer trunks, k2 = coastwise feeders, k3 = overseas. Overseas tags: Hong Kong, Singapur y Suez, Japon, America, Indias Neerlandesas, Espana por Suez.
  - Regenerate: node tools/extract_rings.js (writes /home/claude/rings.json - edit the paths), then python3 tools/route.py (needs numpy, scipy, scikit-image, Pillow).
    Edit the N (nodes), E (domestic links) and OUT (overseas links) lists at the top of route.py, then paste trade_new.json into trade.js.

REPUBLIKA update: tags, country name, HUD
  tags.js / tags.json / tags.csv  1,708 unique three-letter tags: 13 divisions, 48 provinces and districts, 1,647 towns (e.g. MNL Manila, CEB Cebú, ILO Iloílo).
                                  Regenerate with: node tools/make_tags.js. Hand-picked tags live in the RO and PO lists at the top of that script.
  Tags appear in the tooltip and the top-right badge, stand in for names that do not fit, and the "Tags" button (or T key) shows tags only.
  Country name: COUNTRY and CFS at the top of the 'country name' block in app.js. It is set on a spline snapped to the centre of the landmass,
  and letter-spacing is solved so it fills the spline. It fades out as you zoom in, when the division names take over.
  tools/build_single.py builds the one-file preview (republika.html).

Country layer (country.js)
  Built from geoBoundaries ADM0 (tools/ADM0_simplified.geojson, CC BY 4.0) by tools/make_country.py. Draws the gold national territory glow,
  anchors the country name spline, and is the top of the hierarchy: PHL > region > province > town (breadcrumb at top right, click a tag to go back up).
  Labels: names stop growing at a size cap instead of vanishing, shrink to fit when crowded, and fall back to the tag only if they cannot fit at all.

Navigation levels: country (PHL, one realm) > divisions > provinces > towns. The map opens on the country; click it to open the divisions,
Esc (or the breadcrumb at top right) steps back up. Realm colour: CCOL in app.js (deep Spanish gold, #b98507).

Trade tags
  Every trade node (port) has a unique three-letter tag; domestic ports read as P + name (Manila PMN, Iloílo PIO, Cebú PCB, Zamboanga PZM), foreign and overseas ends use
  familiar codes (HKG Hong Kong, SDK Sandakán, JPN Japón, USA América, NEI Indias Neerlandesas, EPA España). Each route has a code FROM-TO (e.g. PMN-PIO) and a class
  (steamer trunk / coastwise feeder / overseas). All of it is in tags.csv (levels trade_node and trade_route), tags.json and tags.js; tools/routes.json lists the routes.
  On the map, port names + tags and overseas destination tags only appear when zoomed in.
  Regenerate with node tools/make_tags.js. Existing geographic tags are never changed by this step.

1892 neighbours: Burma is British (pink), Siam includes Laos (green; Laos east of the Mekong was only taken by France in 1893), French Indochina is Vietnam + Cambodia (blue).
  Built by tools/fix_neighbors.py from Natural Earth 50m borders (public domain). To redo it, reads tools/neighbors.orig.js (the unsplit original) and rewrites neighbors.js:
  python3 tools/fix_neighbors.py ne_50m_admin_0_countries.geojson   (needs: pip install shapely)
